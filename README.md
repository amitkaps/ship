# ship

How every repository builds, checks and deploys, kept as one working example. [The standard](docs/standard.md) says what the one way is, [usage](docs/usage.md) says how to run the commands that keep every repository in line with it, and [the docs](docs/README.md) hold the rest.

It's also the site at [ship.amitkaps.com](https://ship.amitkaps.com), which shows how far each repository has drifted, and the docs.
